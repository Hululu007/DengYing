## 3. 失败路径用例

| # | 条件 | 期望行为 | 验证方式 |
|---|---|---|---|
| F-1 | 缓存目录损坏 | **降级为无缓存直连**，播放不受阻 | 手工破坏目录后播放 |
| F-2 | `SimpleCache` 目录被占用 | 返回 null，走无缓存路径 | 代码审查（`failed` 标志）+ 真机 |
| F-3 | 缓存内容过期 | 重新拉取，不返回旧数据 | UT: `shouldServe` TTL 边界 |
| F-4 | 时钟回拨 | 视为不可用（不"永不过期"） | UT: `时钟回拨时不可命中` |
| F-5 | 分享页解析失败 | 直接换线，不把 HTML 交给播放器 | 探针 `sharePage-unresolved` |
| F-6 | 内嵌播放地址解析失败 | 内嵌位显示错误文案，**不跳页** | 真机 + 探针 `detail-playInline` |
| F-7 | 内嵌态切全屏 | 释放旧引擎 → 新引擎带进度起播 | 真机：进度延续 |
| F-8 | 未选剧集 | 内嵌位显示空态，**不渲染播放器** | 真机截图 |
| F-9 | 缓存容量为 0（回滚开关） | 淘汰所有，功能仍可用 | UT: `容量上限为 0 时全部淘汰` |
| F-10 | 滑动位移未达阈值 | 仍判为点击（切换控制层），不 seek | 真机手感 |
| F-10b | **控制层已自动隐藏时横向滑动** | 浮层与底部进度条同时出现，进度条随手指推进 | 真机：`docs/08` §6.7 已通过；探针 `seek-start ... controls=shown` |
| F-10c | 内嵌位横向滑动 | 同 F-10b；竖向滑动归"作废"，不 seek 也不切控制层 | 真机：`docs/08` §6.7 已通过 |
| F-11 | 竖向拖动起点在左半屏 | 只调亮度，不 seek、不动音量 | 探针：只出现 `gesture-brightness-start` |
| F-12 | 竖向拖动起点在右半屏 | 只调音量，不 seek、不动亮度 | 探针：只出现 `gesture-volume-start` |
| F-13 | 离开播放页 | 窗口亮度覆写被撤掉（`BRIGHTNESS_OVERRIDE_NONE`） | 真机：返回后亮度回到系统值 |
| F-14 | 双击与单击相邻发生 | 双击只切换播放态；单击只切换控制层 | 探针：`gesture-double-tap` 恰出现一次 |
| F-15 | 返回后本页已不是栈顶 | 内嵌位只留黑底，无占位图形/控制栏残留 | 真机：返回过程中观察 |
