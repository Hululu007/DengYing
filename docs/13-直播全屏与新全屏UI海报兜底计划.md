## 1. 目标与范围

本次解决六件事：

1. 直播不应支持暂停。
2. 直播进入全屏应使用分类页进入视频后全屏播放的 UI，而不是旧版 UI。
3. 画面裁剪改到顶栏「投屏」左边，点击展开下拉框，与倍速下拉互斥：同一时间只能出现一个。
4. 新全屏 UI 返回键右边显示影视名称和第几集；没有集数或是电影等系列的，不显示集数。
5. 任何情况下不应出现「有海报却全灰」：尽力显示海报，实在显示不出就做兜底展示。
6. 新全屏 UI 的上下状态栏，在规定时间内无操作后自动隐藏（下拉框打开期间除外）。

不在范围：改旧 `PlayerScreen` 的顶栏底栏排布；增加第四种缩放模式；给直播加暂停、快进、上下集；换海报加载库（不接 Coil）；改三端版本号。本计划不发布 Release。

## 2. 现状事实（来自当前代码，非本次实测）

1. **全屏有两套 UI，直播走错了那一套。** 新 UI 是详情页的 `InlinePlayer(fullscreen = true)`，入口在 `ui/src/commonMain/kotlin/com/dengying/player/ui/pages/DetailScreen.kt:200-201、868`。组件实现在 `ui/src/commonMain/kotlin/com/dengying/player/ui/components/InlinePlayer.kt:76`。直播频道在 `ui/src/commonMain/kotlin/com/dengying/player/ui/pages/LiveChannelsScreen.kt:66-82` 直接走 `Routes.player(..., live = true)`，落到 `NavGraph.kt:234-236` → `PlayerScreen.kt:69` 的旧 UI。
2. **新 UI 顶栏中间是空的。** `InlinePlayer.kt:744-779` 的 `FullscreenTopBar` 只有左侧返回、中间 `Spacer`、右侧「投屏」。`title` 参数在 `InlinePlayer.kt:78` 声明但全文件未使用。画面 `VideoSurface` 在 `InlinePlayer.kt:421` 未传缩放模式，默认 FIT（`ui/src/commonMain/kotlin/com/dengying/player/ui/platform/VideoSurface.kt:38-44`）。
3. **倍速面板和自动隐藏冲突。** 倍速面板在 `InlinePlayer.kt:718-719、784-816`，本地状态 `speedSheet` 在 `InlinePlayer.kt:154`。自动隐藏逻辑在 `InlinePlayer.kt:223-236`：播放中 `delay(3000)` 后隐藏；暂停、缓冲、拖动、seek 时保持显示。计时不检查 `speedSheet`，所以 3 秒后面板跟着栏一起消失。
4. **直播在旧页面仍有暂停。** `PlayerScreen.kt:878-883`、`PlayerViewModel.kt:1195`。进度条已禁用（`PlayerScreen.kt:804-822`），横滑 seek 已直接返回（`PlayerViewModel.kt:1269`）。旧画面裁剪是画面右侧的循环按钮（`PlayerScreen.kt:487-499`），三档 FIT/COVER/FILL 与文案在 `PlayerViewModel.kt:206-221`。
5. **没有 isMovie 字段。** 单集判断用「当前线路只有 1 集」或「集名为空」，不用分类名猜。会话字段 `title` / `vodName` / `episodeName` 在 `shared/src/commonMain/kotlin/com/dengying/player/core/PlaybackSession.kt:55-62`，写入于 `DetailViewModel.kt:755-761`，已抄进 `inlineState.title`（`DetailViewModel.kt:181-183`）。
6. **海报全灰的根因在唯一公共组件。** `ui/src/commonMain/kotlin/com/dengying/player/ui/components/Poster.kt:157-171` 只画 `Box(background(Palette.SearchBg))`，`bitmap != null` 才画 `Image`。空 URL 不请求（`:152`），下载失败（`:110-112、:126-132`）与解码失败都落到同一灰色。已有 https→http 降级和豆瓣 Referer（`PosterFetch.kt:55-59`），失败不入缓存。`MineScreen.kt:180-201、519-532` 已有首字头像兜底，海报没有。

## 3. UI 原型

横屏全屏。点播和直播共用顶栏、底栏；差别只在底栏中间和是否有暂停。

### 3.1 点播全屏（剧集，栏显示）

```
+----------------------------------------------------------+
| [←]  庆余年              第3集          [画面 ▾] [投屏] |
|                                                          |
|                        （画面）                          |
|                                                          |
| 12:04 ━━━━━━●━━ 45:00  [倍速] [⏮][▶][⏭] [⤢]   |
+----------------------------------------------------------+
```

- 返回右边：影视名，再空一格，再集名。集名来自当前集，不拼进标题字符串。
- 电影、单片、没有集名：只显示影视名，不显示集位。判断用「当前线路只有 1 集」或「集名为空」。
- 名称超长单行省略，不挤掉右侧两个按钮。

### 3.2 画面下拉打开（倍速同时关掉）

```
+----------------------------------------------------------+
| [←]  庆余年              第3集       [画面 ▴] [投屏] |
|                                       +--------------+   |
|                                       | 保留比例  ✓ |   |
|                                       | 裁剪铺满     |   |
|                                       | 拉伸铺满     |   |
|                                       +--------------+   |
| 12:04 ━━━━━━●━━ 45:00  [倍速] [⏮][▶][⏭] [⤢]   |
+----------------------------------------------------------+
```

- 下拉贴着「画面」按钮下沿，向下展开。当前项打勾。
- 三档不变：保留比例 / 裁剪铺满 / 拉伸铺满。点一项生效并关闭。
- 再点「画面」或点画面空白处：关闭。
- 此时点「倍速」：画面下拉关闭、倍速下拉打开。反过来一样。不允许两个同时出现。

### 3.3 倍速下拉打开（画面同时关掉）

```
+----------------------------------------------------------+
| [←]  庆余年              第3集          [画面 ▾] [投屏] |
|                                                          |
|                        （画面）                          |
|                                        +--------+        |
|                                        | 0.75x  |        |
|                                        | 1.0x ✓ |        |
| 12:04 ━━━━●━━━ 45:00  [倍速▴] | 1.25x  | [⏭] [⤢] |
|                                        | 1.5x   |        |
|                                        | 2.0x   |        |
|                                        +--------+        |
+----------------------------------------------------------+
```

- 倍速仍从底栏按钮向上弹，档位不变：0.75 / 1.0 / 1.25 / 1.5 / 2.0。
- 下拉开着期间上下栏保持显示，不计时。关掉后重新计 3 秒。

### 3.4 无操作后自动隐藏

```
+----------------------------------------------------------+
|                                                          |
|                                                          |
|                        （画面）                          |
|                                                          |
|                                                          |
+----------------------------------------------------------+
```

- 播放中、没有下拉、没在拖进度：3 秒后顶栏和底栏一起消失。直播也一样。
- 点画面：栏再出来，重新计 3 秒。
- 暂停、缓冲、拖动进度、有错误：栏保持显示，不计时。这条已有，保留。
- 下拉打开：取消计时；关闭下拉：从关闭那一刻重新计 3 秒。

### 3.5 直播全屏

```
+----------------------------------------------------------+
| [←]  湖南卫视                              [画面 ▾] [投屏] |
|                                                          |
|                        （画面）                          |
|                                                          |
| LIVE  ━━━━━━━━━━━━━━  [倍速]           [⤢]   |
+----------------------------------------------------------+
```

- 没有播放/暂停，没有上一集/下一集，没有当前时间和总时长。
- 左下角红色 `LIVE`。进度条画出来但不能拖，横滑不快进。
- 顶栏只显示频道名，不显示「第 N 集」，也不显示「直播」两个字。
- 画面、倍速、投屏、自动隐藏与点播相同。
- 返回：退出直播，回频道列表，不是退到一个详情页。

### 3.6 海报

有地址就尽力显示图。图出来之前、图失败之后，不允许再是一块纯灰。

```
加载中                     失败或空地址
+------------------+        +------------------+
| ██ 浅灰呼吸 ████ |        |     渐变底       |
| ████████████ |        |       庆         |
| ████████████ |        |                  |
+------------------+        +------------------+
```

- 加载中：浅灰呼吸，表示还在拉；跟失败长得不一样。
- 失败或空地址：用片名算一个稳定渐变底（同一个名字总是同一对颜色），正中间放名字的第一个字；没有名字就放播放图标。
- 失败后自动再试 1 次，仍失败就停在兜底，不转圈。
- 直播频道列表今天没有海报，不改。

## 4. 行为规则

| 条 | 规则 |
|---|---|
| 直播不暂停 | 直播不画播放/暂停。点画面只切换栏的显隐，不调暂停；已经在播就保持播。 |
| 直播进全屏 | 频道点击进入新全屏，不进 `PlayerScreen`。 |
| 裁剪位置 | 顶栏投屏左边。点开下拉，不循环。 |
| 下拉互斥 | 倍速与画面同时只能开一个。 |
| 栏自动隐藏 | 播放中 3 秒；下拉开着就暂停；关掉再计时。点播和直播都走这条。 |
| 标题 | 返回右边：影视名，多集再加集名。单集、空集名、直播只显示名称。 |
| 海报 | 有图显示图；没图显示首字渐变；不出现纯灰块。 |

## 5. 要改的文件

- `ui/src/commonMain/kotlin/com/dengying/player/ui/components/InlinePlayer.kt`
  - 顶栏加影视名、集名、画面按钮。
  - 画面下拉，与倍速互斥。
  - 隐藏计时加上「任一下拉打开就不计时」。
  - `live` 时拿掉播放/暂停、上下集、时间，左下改成 `LIVE`，进度条不可拖。
  - `VideoSurface` 接上已有的 `zoomMode`，三档已在 `VideoSurface.kt`，不新增枚举。
- `ui/src/commonMain/kotlin/com/dengying/player/ui/pages/LiveChannelsScreen.kt`

- `ui/src/commonMain/kotlin/com/dengying/player/ui/pages/DetailScreen.kt`
  - 全屏分支能接受直播会话；直播返回回频道列表，不进详情。
- `ui/src/commonMain/kotlin/com/dengying/player/ui/components/Poster.kt`
  - 加载中呼吸；失败/空地址画首字渐变；失败自动重试 1 次。
  - 调用方把已有的标题传进来（首页、分类、发现、搜索、详情、历史、收藏、下载）；没有标题的地方用播放图标。

复用，不新写：

- 缩放三档与文案：`PlayerViewModel.cycleZoomMode()` / `zoomLabel()`（`PlayerViewModel.kt` 约 206–221 行）。全屏改成点选后，循环函数留给旧播放页。
- 倍速面板：`InlinePlayer` 里已有的 `SpeedSheetPanel`；画面下拉按同一个面板样式做，锚点改到顶栏按钮下方。
- 直播进度禁用：对齐 `PlayerScreen` 里 `live` 时进度条 `enabled = false` 的做法。
- 海报下载、解码、豆瓣 Referer、https 降 http：保持 `Poster` 现状，只改画出来的那一层。

## 6. 验证

改完后跑：

1. `rtk gradlew :ui:jvmTest`
2. `rtk gradlew :ui:compileDebugKotlinAndroid`

要补的测试：

- 直播状态不出现播放/暂停调用。
- 单集不显示集名；多集显示影视名和集名；直播只显示频道名。
- 打开画面下拉时倍速下拉为关；反过来也一样。
- 下拉打开时不启动隐藏计时；关闭后才启动。
- 海报：空地址走兜底；失败走兜底；成功仍画图。

真机（vivo V2419A）再看三处：直播全屏是新栏、无暂停、约 3 秒后上下栏消失；点播全屏标题与两个下拉互斥；断网时海报是首字而不是纯灰。未装机前不写「已验证」。实施后把结果写进 `docs/04` / `docs/05`，行为变化同步 `docs/02`。
